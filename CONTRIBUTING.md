# Contributing to Zero English

First of all, thank you for considering contributing to Zero English! ❤️

We welcome contributions from everyone, whether you're fixing a typo, reporting a bug, improving documentation, or implementing a new feature.

## Getting Started

### 1. Fork the Repository

Click the **Fork** button on GitHub to create your own copy of the project.

### 2. Clone Your Fork

```bash
git clone https://github.com/YOUR_USERNAME/zeroenglish.git
cd zero-english
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

## Development Guidelines

### Create a New Branch

Please create a separate branch for every change:

```bash
git checkout -b feature/add-word-search
```

Examples:

- `feature/user-profile`
- `fix/login-bug`
- `docs/update-readme`

### Write Clean Code

- Follow the existing code style.
- Use TypeScript whenever possible.
- Keep functions small and focused.
- Write meaningful variable and function names.
- Remove unused code and imports.

### Commit Messages

Use clear and descriptive commit messages.

Examples:

```text
feat: add word search functionality
fix: resolve pronunciation audio issue
docs: update installation guide
refactor: simplify authentication logic
```

## Pull Request Process

Before opening a Pull Request, make sure:

- Your code builds successfully.
- You have tested your changes.
- You have updated documentation if necessary.
- Your branch is up to date with the latest `main` branch.

After that:

1. Push your branch to GitHub.
2. Open a Pull Request.
3. Clearly describe the changes you made.
4. Wait for review and feedback.

## Reporting Issues

If you find a bug or want to request a feature, please create a GitHub Issue and include:

- A clear title
- Steps to reproduce the problem
- Expected behavior
- Actual behavior
- Screenshots (if applicable)

## Code of Conduct

Please be respectful and constructive when interacting with other contributors.

We want Zero English to be an inclusive and welcoming project for everyone.

## Questions

If you have any questions, feel free to open an issue or start a discussion.

Thank you for contributing to Zero English! 🚀
