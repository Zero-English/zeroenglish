## 📌 About

Zero English is an open-source English learning platform designed primarily for Bengali speakers.

Our mission is simple:

> **Make English learning accessible, free, and understandable for everyone.**

Unlike traditional learning platforms, Zero English provides:

* 🇧🇩 Bengali explanations and meanings
* 🇺🇸 English definitions and examples
* 📚 Structured vocabulary learning
* 🔓 Completely free access
* 🌍 Open-source development

---

## ✨ Features

### 📖 Vocabulary Learning

Learn English words with:

* Bengali meanings
* English definitions
* Example sentences
* Pronunciation support (planned)
* Synonyms and antonyms (planned)

Example:

```json
{
  "id": 1,
  "word": "a, an",
  "meaning_bn": "একটি; একজন; কোনো (অনির্দিষ্ট ব্যক্তি, বস্তু বা বিষয় বোঝাতে ব্যবহৃত)",
  "definition_en": "Used before a singular countable noun when referring to a person or thing for the first time."
}
```

## 🛠 Getting Started

### Prerequisites

Make sure you have installed:

* Node.js (LTS)
* npm
* PostgreSQL

---

### Clone the Repository

```bash
git clone https://github.com/your-org/zeroenglish.git
```

```bash
cd zeroenglish
```

---

### Install Dependencies

```bash
npm install
```

---

### Setup Environment Variables

Create a `.env` file:

```env
DATABASE_URL=
```

---

### Run the Development Server

```bash
npm run dev
```
